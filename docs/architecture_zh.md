# 结构与验证合同

## 路线选择

FreeSewing 是成熟的 JavaScript 参数化二维制版工具，值得作为普通服装基础版型适配器；其当前开发文档在 https://freesewing.dev/reference/api/ ，项目已经从 GitHub 迁到 Codeberg。不能把模板库视为视觉模型或完整缝边图。

本版选择 Python 原创几何 + Blender：可在现有环境直接验证、导出 SVG/PDF/STL，且无需外部模型密钥。代价是这里只实现有限工程原型，版型与工艺的专业验证仍未完成。公开代码和私有角色规格分离。未来可替换二维引擎而保留共同合同。

## 数据合同

CostumeSpec v1 包括 references（来源/哈希）、components（观察事实、制造假设、材料、生成或采购状态）、unknowns、user_overrides。视觉观察不等于对隐藏结构的证明。组件、裁片、缝边、饰件与文件通过稳定 ID 连接。

BodyProfile 明确毫米单位、成年虚构测试身份及 14 个测量值。A 为基准比例，B 较矮且腰围较大，C 较高且肩部较宽。这些是测试输入，不是对真实身体的价值评价，也不是人群统计数据。

Pattern 包括裁剪轮廓、缝合轮廓、经向、命名接缝、裁片数量和尺寸。闭合多边形在 JSON 中以隐式末点至首点表示。缝份不能再次叠加。每个部件记录测试与工艺限制。

AssemblyGraph 记录接缝端点、组装依赖和饰件挂接。Revision 由结构规格、身体数据和引擎版本共同计算。修改材料/闭合假设会让既有输出失效；不得沿用旧文件冒充重新生成。

## 图像入口

live 未配置时直接报 VISION_BACKEND_NOT_CONFIGURED。replay 只重放明确标记且经视觉审阅的参考分析，要求文件哈希一致。没有支持新图推断的后端时，不能声称实现任意图片到生产图纸。

人工可改观察、构造与闭合方案。最终应经过：观察核对 → 拆件确认 → 身体/材料约束 → 几何生成 → 数字校验 → 坯布试穿 → 打印装配试样 → 修订定版。当前只到数字原型阶段。

## 自动化验收

1. 单位、缺失测量、重复组件、未配置模型、错误图像哈希须失败
2. 独立腰围变化须改变腰部，不能让袖长一起等比缩放
3. 裁片不能自交；对应接缝应在记录的松量下匹配
4. 刚体每边两面、法向一致、孔槽贯通、边界尺寸与清单一致
5. BOM 与所有生成部件一致；采购/手工/延期项不伪造制造文件
6. SVG mm 与 PDF 物理页框一致；输出哈希清单可复查
7. Blender 工程能够重新打开；示意图不能称为仿真或合身证明

## 未通过数字测试也不能证明的事项

真实面料垂感、弹性、缝份操作性、胸部塑形、穿脱、皮肤触感、抬臂活动度、耐久性和原角色还原度。所有原型需人工复核和实物试样。
